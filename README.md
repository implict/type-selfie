# TYPE SELFIE — SELPHY CP1500

웹캠으로 촬영한 얼굴을 문구 타이포그래피로 바꾸고, Canon SELPHY CP1500의 4×6 엽서 용지에 인화하는 로컬 웹앱입니다.

## 사용 방법

1. `index.html`을 Chrome 또는 Safari에서 열고 카메라 권한을 허용합니다. 로컬 파일에서 카메라가 차단되면 VS Code Live Server 등 로컬 웹 서버로 열어 주세요.
2. 카메라 시작 → 사진 촬영 → 문구와 표현 방식 조절 → **셀피로 바로 인화**를 누릅니다.
3. 출력 도우미가 켜져 있지 않다면 아래의 1회 설정을 합니다.

## 자동 인화 1회 설정 (Mac)

1. CP1500을 Mac에 USB-C 케이블로 연결하고, **시스템 설정 → 프린터 및 스캐너**에서 `Canon SELPHY CP1500`을 추가합니다.
2. 용지함에는 엽서(Postcard) 용지와 맞는 잉크 카세트를 넣습니다.
3. 터미널에서 다음을 실행합니다.

```sh
cd "01_Projects/Dev/타이포셀피/print-bridge"
npm start
```

터미널은 행사 중 켜 둡니다. 이제 웹앱의 **셀피로 바로 인화** 버튼이 인쇄 대기열에 자동으로 추가합니다.

프린터 이름이 다른 경우에는 다음처럼 실행합니다.

```sh
SELPHY_PRINTER="시스템 설정에 표시된 프린터 이름" npm start
```

출력 도우미는 외부에 공개되지 않고 이 Mac(`127.0.0.1`)에서만 연결을 받습니다. 기본 인쇄 옵션은 4×6 용지 맞춤입니다. CP1500에서 무테/유광 등의 기본값은 시스템 프린터 설정에서 미리 정해 두세요.

## 주변 지우기 (얼굴만 / 인물 전체)

`vendor/` 폴더의 MediaPipe 셀피 분할 모델(Apache-2.0)을 브라우저 안에서만 실행합니다. 사진은 외부로 전송되지 않고 인터넷 연결 없이도 작동합니다. 이 기능은 `http://` 로컬 서버로 열었을 때만 작동합니다(`file://`로 열면 작동하지 않음).

- **얼굴만**: 머리카락·얼굴·안경만 남기고 나머지는 흰 배경
- **인물 전체**: 몸·옷까지 남기고 배경만 흰색
